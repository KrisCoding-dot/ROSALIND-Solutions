# Rosalind Solutions

Solutions to problems from [Rosalind](https://rosalind.info/), a platform for learning bioinformatics and computational biology through problem solving.

## About

This repository contains my solutions to Rosalind exercises, organized by problem and written primarily for learning and reference.

The solutions cover topics such as:

* DNA and RNA processing
* String algorithms
* Probability and statistics
* Combinatorics
* Graph algorithms
* Computational biology

## Note

These solutions are intended for **learning and reference**. If you're working through Rosalind yourself, consider solving each problem independently before looking at the solutions.
